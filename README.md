# Frameworks Front-end - Atividade em Grupo

Este repositório é utilizado com intuitos pedagógicos por um grupo de estudantes da disciplina de Frameworks Front-end do SENAI. Aqui estão reunidas as entregas da atividade proposta, na qual cada integrante do grupo ficou responsável por desenvolver um projeto utilizando um framework/tecnologia front-end diferente.

## Atividade

As entregas deverão ser:

| Projeto | Framework/Tecnologia | Responsável |
|---------|----------------------|-------------|
| Projeto 01 | React | Pedro |
| Projeto 02 | Vue | Gustavo |
| Projeto 03 | Angular | Max |
| Projeto 04 | Next.js | Jeniffer |
| Projeto 05 | git clone de um projeto do GitHub | Felipe |

## Como usar

Cada projeto foi desenvolvido por um integrante do grupo, seguindo a tecnologia definida para a respectiva entrega. Consulte a tabela acima para identificar o responsável e o framework utilizado em cada projeto.
