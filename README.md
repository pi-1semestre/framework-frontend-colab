# Frameworks Front-end - Atividade em Grupo

Este repositório é utilizado com intuitos pedagógicos por um grupo de estudantes da disciplina de Frameworks Front-end do SENAI. Aqui estão reunidas as entregas da atividade proposta, na qual cada integrante do grupo ficou responsável por desenvolver um projeto utilizando um framework/tecnologia front-end diferente.

O tema definido pelo grupo para os projetos foi **animações da Cartoon Network**.

## Atividade

As entregas deverão ser:

| Projeto | Framework/Tecnologia | Responsável | Animação |
|---------|----------------------|-------------|----------|
| Projeto 01 | React | Pedro | Hora de Aventura |
| Projeto 02 | Vue | Gustavo | O Incrível Mundo de Gumball |
| Projeto 03 | Angular | Max | Historietas Assombradas para Crianças Malcriadas |
| Projeto 04 | Next.js | Jeniffer | Steven Universo |
| Projeto 05 | Cópia de um projeto a partir de um repositório | Felipe | Cartoon Network completo |

## Como usar

Cada projeto foi desenvolvido por um integrante do grupo, seguindo a tecnologia definida para a respectiva entrega. Consulte a tabela acima para identificar o responsável e o framework utilizado em cada projeto. Para acessar o código de cada projeto analise a pasta individual de cada um
